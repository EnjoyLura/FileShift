## 1. 产品概述

### 1.1 产品基本信息

| 属性 | 说明 |
|------|------|
| 产品名称 | FileShift |
| 产品类型 | Web 应用（响应式，同时支持 PC 和移动端） |
| Slogan | 文件格式，一键切换 |
| 官网域名 | fileshift.cn（建议） |

### 1.2 产品定位

FileShift 是一款**面向个人用户和小型团队**的在线文件格式转换与处理工具站。

区别于市面上功能单一或收费高昂的转换工具，FileShift 以**积分制**为付费模式，降低用户使用门槛，提供**文档、图片、音视频**三大类格式转换与处理能力，一站式满足日常文件处理需求。

### 1.3 目标用户群体

| 用户类型 | 用户画像 | 核心需求 |
|---------|---------|---------|
| 学生群体 | 大学生、研究生 | 作业/论文格式转换（Word <-> PDF），图片压缩上传 |
| 职场白领 | 办公人员、行政人员 | 文档格式转换、PDF 处理、图片批量处理 |
| 自媒体创作者 | 短视频博主、图文编辑 | 视频/音频格式转换、视频压缩、提取音频 |
| 小型团队 | 创业团队、设计团队 | 批量文件处理、设计稿格式转换 |
| 普通用户 | 有文件处理需求的个人 | 偶尔使用，积分制友好 |

### 1.4 核心价值主张

1. **一站式工具集合**：不需要在多个网站间跳转，文档、图片、音视频全搞定
2. **积分制灵活消费**：用多少付多少，不强制订阅，新用户免费体验
3. **简单易用**：三步完成（上传 → 选参数 → 下载），无需学习成本
4. **安全可靠**：文件处理完成后自动清理，不保留用户文件
5. **多端支持**：手机、电脑都能用，响应式设计

### 1.5 产品差异化优势

| 维度 | 竞品（如 iLovePDF、Convertio） | FileShift |
|------|------------------------------|-----------|
| 付费模式 | 月订阅制，价格较高 | 积分制，按次消费，门槛低 |
| 功能范围 | 通常只支持一类（仅PDF或仅图片） | 三大类一站式 |
| 移动端体验 | 多数未做移动端优化 | 响应式设计，移动端体验良好 |
| 本地化 | 国外产品，访问速度慢 | 国内服务器，访问流畅 |

## 3. 用户体系设计

### 3.1 注册与登录方式

| 登录方式 | 说明 | 优先级 |
|---------|------|-------|
| 微信登录 | 通过微信开放平台 OAuth2.0 授权登录，扫码一键登录 | P0 |
| 邮箱登录 | 邮箱 + 密码注册登录，支持邮箱验证激活 | P0 |
| 手机号登录 | 手机号 + 短信验证码登录，无需设置密码 | P0 |

#### 登录流程说明

**微信登录流程：**
1. 用户点击"微信登录"按钮
2. 展示微信二维码（PC端）或拉起微信授权（移动端）
3. 用户确认授权
4. 获取用户微信基本信息（昵称、头像）
5. 首次登录自动注册并赠送积分
6. 跳转至首页

**邮箱登录流程：**
1. 用户输入邮箱和密码
2. 校验邮箱格式和密码
3. 未激活用户提示发送激活邮件
4. 验证通过，发放 JWT Token
5. 跳转至首页

**手机号登录流程：**
1. 用户输入手机号
2. 点击"获取验证码"（60秒冷却）
3. 输入 6 位数字验证码
4. 验证码校验通过
5. 未注册手机号自动注册并赠送积分
6. 跳转至首页

### 3.2 用户等级体系

| 用户类型 | 获取方式 | 特权说明 |
|---------|---------|---------|
| 游客 | 未登录访问 | 仅可浏览，无法使用功能 |
| 免费用户 | 注册后默认 | 注册赠送 50 积分，可使用所有功能（消耗积分） |
| VIP 用户 | 购买 VIP 套餐 | 每月额外赠送积分，部分功能积分消耗享 8 折，优先处理队列 |

### 3.3 个人中心功能

| 功能模块 | 包含内容 |
|---------|---------|
| 账户信息 | 头像、昵称、绑定邮箱/手机号、微信绑定状态 |
| 积分中心 | 当前积分余额、积分流水明细、积分充值入口 |
| 使用记录 | 历史转换记录、已处理文件下载（24小时内有效） |
| VIP 中心 | 当前 VIP 状态、到期时间、续费/购买入口 |
| 邀请好友 | 专属邀请链接/邀请码、邀请记录、已获积分 |
| 安全设置 | 修改密码、登录设备管理、账号注销 |

### 3.4 账号绑定规则

- 一个账号可同时绑定微信、邮箱、手机号（三种方式均绑定）
- 首次通过任一方式登录即创建账号
- 后续可在个人中心绑定其他登录方式
- 同一微信/邮箱/手机号只能绑定一个账号
- 解绑需至少保留一种登录方式

### 5.2 响应式设计策略

FileShift 采用**响应式设计**，同一套代码同时适配 PC 端和移动端。

| 设备 | 断点 | 布局策略 |
|------|------|---------|
| PC 端 | >= 1024px | 侧边导航 + 内容区域双栏布局 |
| 平板 | 768px - 1023px | 顶部导航 + 内容区自适应 |
| 手机端 | < 768px | 底部导航栏 + 全屏内容区 |

**移动端重点优化：**
- 文件上传支持从手机相册/文件管理器选择
- 微信内打开直接支持微信登录（无需扫码）
- 下载文件调用系统分享/保存功能
- 操作区域适配触摸手势

### 5.3 核心用户流程

#### 流程一：文件转换主流程

```
[选择工具] → [上传文件] → [设置参数] → [确认消耗积分] → [等待处理] → [下载结果]
```

详细步骤：
1. 用户在首页或分类页选择需要的工具，进入工具详情页
2. 点击"上传文件"按钮或拖拽文件到上传区域
3. 根据工具类型设置转换参数（如输出格式、压缩质量等）
4. 点击"开始转换"，弹出积分确认弹窗，显示消耗积分数
5. 确认后扣除积分，任务进入处理队列
6. 显示进度条/加载动画，等待处理完成
7. 处理完成后自动展示结果，提供"下载"按钮

#### 流程二：新用户注册流程


## 6. 商业模式

### 6.1 收入来源

| 收入类型 | 说明 | 预估占比 |
|---------|------|---------|
| 积分销售 | 用户购买积分套餐 | 60% |
| VIP 会员 | 月度/季度/年度 VIP 订阅 | 30% |
| 广告收入（后期） | 非 VIP 用户页面展示广告 | 10% |

### 6.2 积分定价策略

**定价原则：**
- 单次使用成本控制在 ¥0.1 - ¥1 之间，让用户感觉"便宜"
- 批量购买享受折扣，鼓励大额充值
- VIP 用户享受额外折扣，增加 VIP 吸引力

**积分消耗定价依据：**
- 服务器计算资源消耗（CPU/内存/时间）
- 第三方服务成本（如 AI 去背景的 API 调用费）
- 用户使用频率（高频功能定价低，低频功能定价高）

### 6.3 VIP 会员价值设计

VIP 会员除了积分优惠外，还提供：
- 优先处理队列（高峰期优先）
- 更高的文件上传大小限制（普通用户 50MB，VIP 200MB）
- 批量处理更多文件（普通用户 10 个，VIP 50 个）
- 文件保留时间更长（普通用户 24 小时，VIP 72 小时）
- 无广告体验

### 6.4 未来变现扩展

- **企业版/团队版**：为小型团队提供多账号共享积分方案
- **API 开放平台**：向开发者开放文件转换 API，按调用量计费
- **广告合作**：流量达到一定规模后接入 Google AdSense 或国内广告联盟
- **增值服务**：OCR 文字识别、AI 翻译等高级功能

## 9. 风险与应对

| 风险 | 风险等级 | 应对策略 |
|------|---------|---------|
| 文件处理失败率高 | 高 | 充分测试各格式兼容性，失败退还积分 |
| 服务器资源不足 | 中 | 任务队列削峰，异步处理，限制并发 |
| 恶意上传（病毒/大文件） | 中 | 文件类型校验、大小限制、病毒扫描 |
| 积分系统被刷 | 中 | 邀请限制、行为风控、异常检测 |
| 合规风险（用户隐私） | 中 | 文件定期清理，隐私协议，不保留用户数据 |
| 微信登录审核不通过 | 低 | 先上线邮箱/手机登录，微信登录后续接入 |
